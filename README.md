# TaskFlow API

## Project Overview

TaskFlow API is a backend project intended to provide RESTful services for task management.

The project is currently in its initial setup phase.

## Technology Stack

The following technologies are planned for the project:

- Java
- Spring Boot
- Maven
- Spring Boot Actuator

Additional technologies and dependencies will be defined during the upcoming development stages.

## Development Workflow

Development follows a branch-based Git workflow.

- The `main` branch serves as the primary project branch.
- Each Jira task is implemented in a separate branch.
- Branch names follow the format `SCRUM-XX-short-description`.
- Changes are submitted through Pull Requests.
- Code Review approval is required before merging.

For detailed branching, commit, and Pull Request conventions, see [Git Flow](docs/gitflow.md).
